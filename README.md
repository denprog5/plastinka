# Пластинка

Плеер «Сейчас играет» для стрима: показывает в OBS трек, который играет в Spotify, — обложка, название, исполнитель и полоса прогресса в стиле канала: полупрозрачное стекло с бликом и красный глитч. Живёт в трее, ничего не спрашивает и не требует входа в Spotify.

## Как пользоваться

1. Установите `Plastinka-Setup-<версия>.exe` (права администратора не нужны) и запустите. При первом запуске ссылка для OBS сама скопируется в буфер обмена.
2. В OBS: **Источники → + → Браузер**, в поле URL вставьте `http://127.0.0.1:7720/`, ширина **640**, высота **200**. Остальные настройки источника не трогайте.
3. Включите музыку в Spotify — карточка выедет. На паузе через 2 секунды уедет обратно.

Меню трея:

- **Скопировать ссылку для OBS** / **Открыть плеер в браузере** — проверить, как выглядит.
- **Тема** — оформление карточки (см. ниже). Меняется сразу, в том числе в уже открытом OBS.
- **Любой плеер, не только Spotify** — Яндекс Музыка, YouTube в браузере, AIMP и всё, что показывает трек в системном оверлее громкости Windows.
- **Запускать вместе с Windows**.
- **Проверить обновления** — программа и сама проверяет GitHub через 15 с после запуска и раз в 6 часов. Найденное сразу после запуска ставится само (обычно это до стрима); найденное позже — только пункт «Установить обновление», чтобы не перезапускаться посреди трансляции.

Длинное название или исполнитель, которые не помещаются, едут бегущей строкой туда-обратно с паузами на краях — только пока карточка на экране.

Параметры в адресе источника (можно сочетать через `&`):

| Адрес | Что делает |
|---|---|
| `http://127.0.0.1:7720/?progress=0` | без полосы прогресса: страница вообще не перерисовывается между треками |
| `http://127.0.0.1:7720/?always=1` | не прятать карточку на паузе |
| `http://127.0.0.1:7720/?demo=1` | пример с выдуманными треками — чтобы расставить источник без музыки |
| `http://127.0.0.1:7720/?tint=0.6` | плотность тонировки стекла: 0 — почти прозрачное, 1 — сплошное тёмное (по умолчанию 0.38). Для очень светлых игр сделайте плотнее |
| `http://127.0.0.1:7720/?theme=imperium` | другое оформление, см. ниже |

Оформления карточки — в меню трея **Тема** или параметром `?theme=` в адресе (он важнее меню: так можно поставить разные темы в разных сценах). Размер источника у всех тот же — 640 × 200:

| Тема | Как выглядит |
|---|---|
| `glitch` (по умолчанию) | стекло, красная глитч-полоса на верхнем крае и вспышка при смене трека |
| `clean` | то же самое, но без красной полосы сверху |
| `imperium` | готика: тёмная плита со скошенными углами, двойная золотая рамка, крылатый череп сверху, шрифт с засечками |
| `neon` | синтвейв: сетка на горизонте, светящаяся кромка «маджента → циан» |
| `terminal` | зелёный терминал: моноширинный шрифт, строки развёртки, сегментная шкала, обложка в зелёном |

Например: `http://127.0.0.1:7720/?theme=clean&tint=0.5`. Посмотреть тему без музыки — добавьте `&demo=1`.

Стекло не размывает игру под собой: источник «Браузер» в OBS не видит сцену за карточкой, поэтому игра просвечивает сквозь тонировку без размытия.

Настройки — `%APPDATA%\Plastinka\config.json`: `port` (если 7720 занят), `any_player`, `auto_update`, `theme`.

## Откуда берётся трек

Spotify для компьютера сам сообщает Windows, что играет (так работает оверлей громкости и медиа-клавиши). Пластинка читает это через системные медиа-контролы (GSMTC): без API-ключей, без интернета (он нужен только для проверки обновлений) и без опроса — программа спит, пока Windows не скажет, что трек, пауза или позиция поменялись. Нужен именно Spotify для компьютера (не веб-плеер; с веб-плеером включите «Любой плеер»).

## Нагрузка

- Программа: 0% CPU в простое и при игре музыки, ~3 МБ личной памяти, exe < 1 МБ.
- Страница в OBS статична: анимации идут только при смене трека и показе/скрытии, прогресс обновляется раз в секунду (`?progress=0` убирает и это). Бегущая строка двигается только у не помещающегося названия.

## Сборка

```
cargo build --release
python tools/prep.py   # только если меняли картинки в source/
powershell -ExecutionPolicy Bypass -File scripts/build-installer.ps1   # → dist/Plastinka-Setup-<версия>.exe
```
